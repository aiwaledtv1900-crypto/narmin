# نارمين — Narmin

**لغة برمجة عربية تبني تطبيقات Android حقيقية**

نارمين لغة برمجة عربية-إنجليزية حديثة، تُترجم إلى Kotlin + XML، وتبني تطبيقات Android حقيقية قابلة للتثبيت على هاتفك.

**من Terminal إلى تطبيق على هاتفك — بدون كتابة سطر Kotlin واحد.**

## المميزات

- 🌍 عربية + إنجليزية — `اطبع` أو `print` — كلاهما يعمل
- 📱 تطبيقات Android — Codegen كامل إلى Kotlin + XML
- 🎨 1,500+ لون مع معدلات درجة
- 💬 اقتراح ذكي — يُصحّح أخطاءك تلقائياً
- 🤖 الوضع الطبيعي — اكتب عربية عادية → تطبيق كامل
- 🔧 Termux + APK مدمجين
- 📦 حفظ دائم (SharedPreferences + JSON)
- 🌐 HTTP/APIs

## التثبيت على Termux

**سطران فقط:**

    pkg install -y git
    git clone https://github.com/USERNAME/narmin.git ~/DEV/apps_building/narmin
    cd ~/DEV/apps_building/narmin
    bash install.sh

**سيُثبّت تلقائياً:**
- Node.js
- Java 17 (لبناء APK)
- أدوات Android (aapt2, zipalign, apksigner)
- الأدوات المساعدة

**ثم استخدم:**

    narm               # الوضع الطبيعي بالعربية
    narm repl          # REPL البرمجة
    narm run file.narm # تشغيل ملف

## البداية السريعة

### الوضع الطبيعي (الأسهل)

    narm

ثم اكتب:

    نارمين » انشئ تطبيق "مذكرتي"
    نارمين » أضف عنوان "مذكراتي اليومية"
    نارمين » أضف زر "احفظ"
    نارمين » شغّل

**النتيجة:** تطبيق على هاتفك.

### تشغيل ملف

    narm run examples/hello.narm

محتوى `hello.narm`:

    اطبع "مرحباً يا DEV"

### REPL البرمجة

    narm repl

## البنية

    src/
    ├── lexer/        ← تحويل النص إلى رموز
    ├── parser/       ← بناء شجرة AST
    ├── interpreter/  ← تنفيذ الشجرة
    ├── stdlib/       ← Termux + APK + Android
    ├── codegen/      ← نارمين → Kotlin + XML
    ├── natural/      ← الوضع الطبيعي + الألوان
    └── repl.js       ← REPL
