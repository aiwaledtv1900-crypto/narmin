## ما هي نارمين؟

نارمين لغة برمجة صغيرة وسريعة، تكتب بها سكربتات أتمتة بأسلوب نظيف:

- **كلمات مفتاحية عربية وإنجليزية** — `اطبع` أو `print`، كلاهما يعمل
- **أنواع ديناميكية** — سريعة وبسيطة
- **ناقل الأنابيب `|>`** — ربط الدوال بأناقة
- **if-expression** — قيمة شرطية داخل التعبيرات
- **وحدة Termux مدمجة** — `شغل`, `اقرأ`, `اكتب`, `موجود`
- **وحدة APK مدمجة** — `apk_فك`, `apk_أعد_بناء`, `apk_وقّع`, `apk_معلومات`
- **REPL تفاعلي** — اختبر أي كود فوراً

## التثبيت

### من npm (بعد النشر)

    npm install -g narmin

### محلياً (للتطوير)

    cd ~/DEV/apps_building/narmin
    npm link

الآن الأمران `narm` و `narmin` جاهزان في PATH.

## أمثلة

### مرحباً بالعالم

    اطبع "مرحباً يا DEV"

### دالة

    دالة جمع(ا، ب) {
      ارجع ا + ب
    }
    اطبع جمع(3، 4)

### ناقل الأنابيب

    دالة ضعف(س) { ارجع س * 2 }
    متغير نتيجة = 5 |> ضعف |> ضعف
    اطبع نتيجة

### if-expression

    متغير عمر = 25
    متغير حالة = اذا عمر >= 18 { "بالغ" } والا { "قاصر" }
    اطبع حالة

### تعديل APK

    متغير info = apk_معلومات("تطبيق.apk")
    اطبع info.حزمة

    متغير مجلد = apk_فك("تطبيق.apk").مجلد
    apk_بدّل_نص(ضم(مجلد، "res/values/strings.xml")، "Hello"، "مرحبا")
    متغير جديد = apk_أعد_بناء(مجلد).مسار
    apk_وقّع(جديد، { keystore: ابحث_keystore() })

## البنية

    src/
    ├── lexer/         ← تحويل النص إلى رموز
    ├── parser/        ← بناء شجرة AST
    ├── ast/           ← تعريف العقد
    ├── interpreter/   ← تنفيذ الشجرة
    ├── stdlib/        ← المكتبة القياسية
    ├── repl.js        ← الواجهة التفاعلية
    ├── cli.js         ← الأداة الرئيسية
    └── index.js       ← نقطة الدخول

## الكلمات المفتاحية

| عربي | إنجليزي | الاستخدام |
|------|---------|-----------|
| اطبع | print | طباعة |
| متغير | let | تعريف متغير |
| ثابت | const | تعريف ثابت |
| اذا | if | شرط |
| والا | else | بديل |
| طالما | while | حلقة |
| لكل | for | حلقة |
| في | in | داخل |
| دالة | function | تعريف دالة |
| ارجع | return | إرجاع |
| صحيح | true | قيمة صحيحة |
| خطأ | false | قيمة خاطئة |
| عدم | null | لا شيء |
